# BaBBled Surreal Editorial Shopify Theme

Production-oriented Shopify Online Store 2.0 theme foundation for BaBBled LLC.

## Visual system

- Adobe Stock blindfolded woman: editorial hero only
- Original Brooke Howard artwork: all sellable product imagery
- Licensed bird and Morris assets: decorative or resale use within their licenses
- Palette: parchment, teal-grey, dusty rose, charcoal
- Motion: lightweight SVG butterflies, transform/opacity animation, reduced-motion support

## Included

- Responsive editorial homepage
- Trust strip
- Asymmetric original-art product grid
- Artist-story section
- Product detail template
- Responsive images with `srcset` and lazy loading
- Deferred vanilla JavaScript
- Product-only CSS loaded conditionally

## Install

1. Copy the contents of `shopify-theme/` into an unpublished Shopify theme.
2. In the theme editor, select the Adobe hero image and mobile crop.
3. Assign an original-art collection to the art-grid section.
4. Add original artworks to products before publishing.
5. Preview and test mobile, cart, checkout, accessibility, and image licensing.

The connected Shopify write tool was unavailable during this build, so this repository branch is the source package for deployment.
